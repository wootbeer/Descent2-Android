Descent II (1996) Android
=========================

This is a source port of the original DOS game “Descent II” for Android. You will need the game files from a licensed copy in order to play it.  

Game Files
-------
Place these files from your copy of Descent II onto your device, all in one folder:  

- DESCENT2.HOG  
- DESCENT2.HAM  
- DESCENT2.S22 (or DESCENT2.S11)  
- GROUPA.PIG  

Optional, copied when present:  

- ALIEN1.PIG, ALIEN2.PIG, FIRE.PIG, ICE.PIG, WATER.PIG for the extra level texture sets  
- INTRO-H.MVL (or INTRO-L.MVL), OTHER-H.MVL (or OTHER-L.MVL), ROBOTS-H.MVL (or ROBOTS-L.MVL) for the cutscene movies  

Filenames and extensions should be in uppercase. GOG versions of the files should work.

On first launch the game will ask you to select the folder with these files.  
The first four files above are required.  
If it closes you are not using the correct version of the files.  

Add-on Mission Packs
-------
Fan-made and commercial add-on missions (a `.MN2` file plus its matching `.HOG` file) can be 
imported from the same folder picker on first launch, or at any time from Options > Add Mission Packs.  
Imported missions show up in the New Game mission list. 
Missions that need files they don't ship with are reported with an error message instead of starting.  

Redbook (CD) Music
-------
Optional. To use the CD audio put your tracks in the same folder as your game files. 
Each file name must start with the 2-digit track number and use a supported format (OGG, MP3, WAV, FLAC, M4A),
for example `02.ogg` or `04 Level Music.mp3`. They are copied on launch, or later from Options > Add Mission Packs.  

Controls
-------
Auto show/hide on-screen touch controls.  
Optimized for handhelds.  

Android Handhelds / Retroid Devices:    
Make sure controller style is set to Retro or whatever your devices default is. 
Ntndo style as opposed to Xbox style, swipe down menu to access these options.  

Switch to Modern stick layout from remap menu if desired for fps style controls.  

Gyro works.
